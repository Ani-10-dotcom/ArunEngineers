# Arun Engineers – Website

One-page website for **Arun Engineers**, builders & contractors in Erode, Tamil Nadu.

- `index.html` – the whole site (HTML + CSS + a little JavaScript, no build step)
- `hero.jpg` – hero photo

## Run locally
Open `index.html` in any browser.

## Deploy
Hosted on Vercel as a static site (no framework, no build command). Every push to `main` redeploys.
